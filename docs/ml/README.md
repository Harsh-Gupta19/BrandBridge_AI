# Machine Learning Roadmap

The future recommendation system will compare:

- Logistic Regression
- Random Forest
- XGBoost

Potential features:

- `category_similarity`
- `audience_match`
- `country_match`
- `platform_match`
- `budget_match`
- `engagement_rate`
- `follower_score`
- `semantic_similarity`
- `creator_reliability`

Phase 1 does not train a model, select final weights, or expose recommendations as production behavior.
