# Documentation Index

This folder explains how BrandBridge AI is organized and how future features should be added.

Start here if you are new:

1. `README.md` at the repository root for the product overview.
2. `docs/project-structure.md` for a folder-by-folder guide.
3. `backend/README.md` if you are working on FastAPI, database, AI, ML, or integrations.
4. `frontend/README.md` if you are working on React screens.
5. `docs/architecture/ai-agent-workflow.md` if you are working on LangChain, LangGraph, RAG, or agents.

Important docs:

- `architecture/` explains system design and future workflows.
- `api/` explains backend API conventions.
- `ml/` explains the recommendation model roadmap.
- `rag/` explains retrieval-augmented generation planning.
- `integrations/` explains external integrations such as MCP and social APIs.
- `observability/` explains future monitoring and tracing decisions.
- `decisions/` contains Architecture Decision Records.
- `demo-scenario.md` describes the future target demo flow.
