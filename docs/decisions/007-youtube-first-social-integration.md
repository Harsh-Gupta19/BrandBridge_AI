# 007 - YouTube-First Social Integration

## Status

Accepted

## Context

Creator metrics will eventually improve recommendations. YouTube provides a clear path for channel verification and authorized analytics in many creator workflows.

## Decision

Prioritize YouTube integration before broader social integrations, while preserving an Instagram module boundary.

## Alternatives Considered

- Instagram first
- Build all social integrations together
- Delay social integrations entirely

## Consequences

The team can validate one social integration deeply before broadening scope. The platform must still work when social APIs are unavailable.
