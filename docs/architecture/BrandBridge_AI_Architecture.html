4. Data Flow: End-to-End Request Lifecycle

Sequence Flow 
sequenceDiagram
    autonumber
    participant U as 🖥️ Browser
    participant FE as ⚛️ React Frontend
    participant API as 🐍 FastAPI Route
    participant SVC as Service Layer
    participant Agent as 🤖 LangGraph Agent
    participant ML as 📊 ML Module
    participant RAG as 📚 RAG Engine
    participant LLM as 🧠 LLM Provider
    participant DB as 💾 PostgreSQL + pgvector
    participant Social as 🔌 Social APIs

    U->>FE: Submits campaign brief & clicks "Find Creators"
    FE->>API: POST /api/v1/recommendations
    API->>SVC: create_recommendations()
    SVC->>Agent: creator_matching_graph.invoke()

    Agent->>DB: Search candidate creators (SQL + pgvector)
    DB-->>Agent: Creator candidates pool

    Agent->>Social: Fetch live social statistics
    Social-->>Agent: YouTube/Instagram/Bluesky metrics

    Agent->>ML: calculate_ml_match()
    ML-->>Agent: ML compatibility scores

    Agent->>DB: Semantic similarity search (pgvector)
    DB-->>Agent: Embedding cosine distances

    Agent->>RAG: Retrieve brand guidelines
    RAG->>DB: Vector search on guideline chunks
    DB-->>RAG: Relevant guideline text
    RAG-->>Agent: Context for explanation

    Agent->>LLM: Generate explanation
    LLM-->>Agent: Human-readable rationale

    Agent-->>SVC: Ranked results + explanations
    SVC-->>API: Response payload
    API-->>FE: JSON response
    FE-->>U: Display creator recommendation cards

    Note over U, FE: Human-in-the-Loop Step
    U->>FE: Approve match & click "Send Proposal"
    FE->>API: POST /api/v1/proposals
    API->>SVC: create_proposal()
    SVC->>DB: Save proposal (status: PENDING)
    DB-->>SVC: Persisted
    SVC-->>API: Proposal created
    API-->>FE: 201 Created
    FE-->>U: Display proposal confirmation
