# Observability

Observability means understanding what the application is doing while it runs.

Examples:

- Logs
- Error tracking
- API metrics
- LLM call tracing
- Token usage tracking
- Agent workflow traces

Current status:

- Basic Python logging is configured.
- No external observability platform is integrated yet.
- Helix is not integrated yet.

Future observability should be added gradually when there is a concrete debugging or demo need.
