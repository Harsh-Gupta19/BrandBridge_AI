# ML Module

The recommendation system will compare Logistic Regression, Random Forest, and XGBoost models.

Planned features include:

- `category_similarity`
- `audience_match`
- `country_match`
- `platform_match`
- `budget_match`
- `engagement_rate`
- `follower_score`
- `semantic_similarity`
- `creator_reliability`

No final scoring weights are hardcoded in Phase 1. Experiments should live in notebooks or training modules before production APIs consume them.
